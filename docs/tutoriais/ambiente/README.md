# Tutoriais de ambiente

Esta trilha documenta como configurar e executar o projeto em ambientes
separados.

## Conteúdos

1. [Múltiplos ambientes](01-multiplos-ambientes.md)
2. [Compose com PostgreSQL](02-compose-postgresql.md)

O tutorial apresenta os arquivos Compose e de configuração usados em
desenvolvimento, staging e produção simulada, além das diferenças de portas,
volumes, redes e reload.

## Observação

Staging e produção são simulações locais para aprendizado. Eles não
representam uma infraestrutura corporativa completa nem substituem secrets
manager, CI/CD, observabilidade, backups ou alta disponibilidade.
